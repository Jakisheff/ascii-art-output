# ASCII-Art-Output

Добро пожаловать в проект **ASCII-Art-Output**! 🎉

Этот проект — программа на языке Go, которая берет обычный текст и превращает его в большую, красивую ASCII-графику. 
Но главная особенность этой версии: мы можем не только выводить текст на экран, но и **сохранять результат в отдельный текстовый файл**!

## 🚀 Как это работает?

Вам нужно открыть терминал (командную строку) в папке с этим проектом и запустить программу командой `go run .`. Вы можете передать программе от 1 до 3 аргументов:

1. **Текст** (обязательно) — то, что мы хотим нарисовать.
2. **Флаг `--output=<имя_файла.txt>`** (по желанию) — специальная команда, чтобы сохранить результат в файл.
3. **Баннер** (по желанию) — стиль шрифта (`standard`, `shadow`, или `thinkertoy`).

---

## 📖 Примеры использования

### 1. Самый простой запуск (только текст)
Если вы просто передадите текст (в кавычках, если есть пробелы), программа выведет ASCII-арт прямо в терминал:
```bash
go run . "Hello World"
```

### 2. Запуск с выбором стиля (баннера)
Если вы хотите использовать стиль `shadow` (или `thinkertoy`):
```bash
go run . "Hello World" shadow
```

### 3. Сохранение результата в файл (Главная фишка! 💾)
Если вы хотите сохранить текст в файл, добавьте флаг `--output=имя_вашего_файла.txt` перед текстом:
```bash
go run . --output=banner.txt "Hello World" standard
```
> *После этого загляните в папку с проектом — там появится новый файл `banner.txt` с вашим красивым артом!*

Вы можете прочитать содержимое созданного файла прямо в терминале с помощью команды `cat`:
```bash
cat -e banner.txt
```

## 🛠 Особенности кода для новичков

Код написан так, чтобы его было легко понять:

* **Проверка флагов (`main.go`)**: Мы берем аргументы командной строки (`os.Args`) и просто смотрим, не начинается ли первый из них с текста `--output=`. Если да, мы "сдвигаем" проверки так, чтобы следующее слово воспринималось как текст для рисования. 
* **Генерация ASCII (`ascii.go`)**: Тут происходит сама магия. Буквы состоят из 8 строчек. Программа берет каждый символ вашего текста, находит его в "баннере" (шаблоне) и по очереди клеит их строка за строкой!
* **Защита баннеров (`banners.go`)**: В файле есть словарик `expectedHashes`. Он использует алгоритм шифрования `SHA-256`, чтобы перед каждым запуском проверять, не изменил ли кто-то (или не сломал ли) оригинальные файлы шаблонов (`standard.txt`, `shadow.txt`, `thinkertoy.txt`). 

## 🧪 Запуск тестов

В проекте уже написаны автоматические тесты, которые проверяют всё за вас. Чтобы убедиться, что всё работает, введите:
```bash
go test -v .
```
В конце вы должны увидеть зеленое слово `PASS`.
